## 📌 О проекте

Симулятор чачки - это **текстовая игра** об придуманном питомце под именем "Чачка" Написанная на Python 3.14

## 📌 текущие результаты

Версия игры: v0.01.5
Полноценно играть: ✅**возможно**

## зависимости

* rich - библиотека для цветного текста, прогресс баров и различных вещей, используется для цветного вывода

## ❌ недостатки
* нет полного GUI
* читы неполные

## ✅ возможности
* ✅ чачка умеет Викать и Кричать и кушать и перемещаться
* ✅ у чачки есть Хп и еда
* ✅ есть обработка методов при мертвой чачке
* ✅ чачка умеет поглощать зелья
* ✅ X, Z и карта
* ✅ есть стамина у чачки
* ✅ есть эффекты (моментальная регенерация)
* ✅ собственная отрисовка карты по команде
* ✅ базовое внутриигровое время

* ✅ имеется чит на изменение HP
* ✅ имеется чит на изменение стамины
* ✅ имеется чит на изменение сытости
* ✅ имеется чит на пере-регенерацию карты

## запуск симулятора

* **Запустить игру:** `python start.py`
* **Запустить игру (читы):** `python start.py --cheats`
* **Установить зависимости:** `python manage.py install`
* **Очистка логов:** `python manage.py clean log`
* **Очистка кеша:** `python manage.py clean cache`
* **Очистить и кеш и логи:** `python manage.py clean`
