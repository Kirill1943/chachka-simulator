## 📌 О проекте

Симулятор чачки - это **текстовая игра** об придуманном питомце под именем "Чачка" Написанная на Python 3.14

## 📌 текущие результаты

Версия игры: v0.01.7
Полноценно играть: ✅**возможно**

## зависимости

* rich - библиотека для цветного текста, прогресс баров и различных вещей, импользуется для цветного вывода
* pick - библиотека для интерактивного выбора вариантов

## ❌ недостатки
* нет полного GUI
* читы неполные

## ✅ возможности
* ✅ есть базовые методы чачки (поедание еды, ходьба)
* ✅ есть показатели здоровья, сытости и выносливости
* ✅ Координаты и карта по которой возможно ходить
* ✅ Есть эффекты (пока 1)
* ✅ собственная отрисовка карты
* ✅ базовое внутриигровое время

* ✅ имеется чит на изменение HP
* ✅ имеется чит на изменение стамины
* ✅ имеется чит на изменение сытости
* ✅ имеется чит на регенерацию карты
* ✅ имеется чит на бессмертие

## запуск симулятора

* **Помощь:** `python manage.py help`
* **Запустить игру:** `python start.py`
* **Запустить игру (читы):** `python start.py --cheats`
* **Установить зависимости:** `python manage.py install`
* **Очистка логов:** `python manage.py clean log`
* **Очистка кеша:** `python manage.py clean cache`
* **Очистить и кеш и логи:** `python manage.py clean`
